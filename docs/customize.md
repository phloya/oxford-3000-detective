# Настройка под себя

[English](./customize.en.md)

Правки стиля делаются в Anki на компьютере: **Инструменты → Управление типами записей** (Tools → Manage Note Types) → «Do Not Give It Back (Oxford 3000)» → **Карточки…** (Cards…) → вкладка **Оформление** (Styling). Правило вставляется в самый конец и подхватывается на всех устройствах после синхронизации.

Оба рецепта ниже проверены на настоящей карточке колоды.

## Только слово на лицевой стороне

По умолчанию на лицевой стороне видны слово и фрагмент истории. Если хочешь вспоминать слово без подсказки контекстом, спрячь фрагмент:

```css
.front .ex-story { display: none; }
```

Ярлык документа останется: он не выдаёт значение слова. Фрагмент появится на обороте.

## Без рисунков и сцен

```css
.wpic, .back .art-panel { display: none !important; }
.back:has(.wpic) .word, .back:has(.wpic) .ru { margin-right: 0; min-height: 0; }
```

Вторая строка убирает отступ, который оставлен под рисунок.

## Сколько новых карточек в день

Шестерёнка у колоды → **Параметры** (Options) → **Лимиты** (Daily limits) → **Новых карточек в день** (New cards/day). Одна серия — 17 карточек. Хочешь читать больше — подними лимит на сегодня.

Перемешивать новые карточки нельзя. Их порядок — это порядок сюжета.

## Что не настраивается

- **Перевод только русский.**
- **Шрифты грузятся из Google Fonts.** Без интернета Anki возьмёт запасные (Georgia, PT Serif, Consolas). Карточки работают, но выглядят проще.
